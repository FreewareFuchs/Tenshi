# Bei Tenshi mitarbeiten

Vielen Dank für dein Interesse an Tenshi!

- Zuerst ein Issue für den Fehler oder Änderungsvorschlag öffnen (ohne private Dateinamen, Images oder Logs).
- Änderungen möglichst klein halten und den schreibgeschützten Zugriff auf **Quellmedien** niemals aufweichen.
- Keine automatischen Schreiboperationen auf Quelldatenträger, Partitionstabellen oder Dateisystem-Metadaten einführen.
- Auf Windows `run_tests.bat --no-pause` ausführen; plattformübergreifend `python -m unittest discover -s tests -q`.
- Pull Requests sollten Zweck, Risiken, Tests und Auswirkungen auf NTFS/FAT32/exFAT/ext4 beschreiben.
- Keine urheberrechtlich geschützten Codefragmente oder Datenträger-Images ohne ausreichende Lizenzrechte einreichen.
- Mit dem Einreichen von Änderungen bestätigst du, dass du zu deren Veröffentlichung unter der MIT-Lizenz berechtigt bist.
- Sicherheitsschwachstellen bitte entsprechend `SECURITY.md` melden.

Ein Pull Request ist keine Zusage auf Übernahme oder auf einen bestimmten Supportzeitraum.
