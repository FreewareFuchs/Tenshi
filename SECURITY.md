# Sicherheitsmeldungen / Security Policy

Tenshi ist experimentelle Datenrettungssoftware. Eine unbeabsichtigte Schreiboperation auf Quellmedien oder das falsche Lesen eines Datenträgers ist besonders kritisch.

## Bitte keine sensiblen Daten öffentlich veröffentlichen

Keine vollständigen Datenträger-Images, privaten Dateinamen, Pfade, personenbezogenen Daten oder vertraulichen Logs in öffentliche Issues hochladen.

Für Sicherheitslücken möglichst die private **Report a vulnerability**-Funktion des GitHub-Repositories nutzen, *falls* diese vom Repository-Betreiber aktiviert wurde. Andernfalls nur eine allgemeine, nicht ausnutzbare Anfrage im Issue-Bereich hinterlassen und um einen privaten Meldeweg bitten. Es ist noch keine Sicherheitskontaktadresse festgelegt.

## Umfang

Version 3.0.2 Beta ist experimentell. Es gibt keine Zusage zu Wartungsfristen oder Sicherheitsupdates. Nutzer sollten Images und Exporte stets auf getrennte Medien schreiben und wichtige Originale nach Möglichkeit schonen.
